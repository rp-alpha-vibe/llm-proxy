# Claude Code project instructions

@AGENTS.md

`AGENTS.md` — канонический общий регламент проекта.

Канонические skills находятся в `.agents/skills/<name>/SKILL.md`.
В `.claude/skills/<name>` размещены относительные symlinks на те же каталоги для нативной загрузки Claude Code; независимых копий инструкций нет.

Если skill не появился среди доступных или checkout не поддерживает symlinks (например, на Windows), прочитай `.agents/skills/<name>/SKILL.md` напрямую по trigger-условиям из `AGENTS.md` и выполни его инструкции. Текстовый файл с адресом symlink не является содержимым skill.

`grill-me` применять только по явному запросу пользователя: `$grill-me` или `/grill-me`.
Для проверки подключения посмотри список доступных skills; при отсутствии регистрации используй прямое чтение. Не устанавливай дополнительные плагины для этого fallback.

Общие правила не дублировать здесь: они меняются только в `AGENTS.md`.
