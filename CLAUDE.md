# Claude Code project instructions

@AGENTS.md

`AGENTS.md` — канонический общий регламент проекта.

Claude Code должен:

- читать только релевантный контекст, а не весь репозиторий;
- использовать project-local skills из `.agents/skills/` по их trigger-условиям;
- для нетривиальной задачи сначала сформулировать Goal / Plan / Acceptance / Verification / Risks;
- не начинать реализацию, если materially важное решение требует владельца;
- после реализации выполнять отдельный review-проход и свежие проверки;
- не считать собственное утверждение доказательством;
- не писать реальные ПД, секреты и runtime payloads в репозиторий или вывод.

Общие правила не дублировать здесь: они меняются только в `AGENTS.md`.
