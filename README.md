# llm-proxy

Модуль обнаружения, маскирования и демаскирования персональных данных для хакатона Альфавайб.

## Текущий этап

Подготовлены требования и правила работы ИИ. Каркас сервиса, команды запуска, тесты и CI пока не реализованы; готовность к сдаче не подтверждена.

## Работа в проекте

- [AGENTS.md](AGENTS.md) — общий процесс и объём проверок.
- [Требования](docs/REQUIREMENTS.md) — ТЗ, локальная проверка качества и открытые вопросы.
- [Решения](docs/DECISIONS.md) — принятые решения и причины.

Реализацию выполняет DeepSeek. Общая точка входа — `AGENTS.md`, канонические skills находятся в `.agents/skills/`.
Если используемый клиент не загружает инструкции автоматически, передать ему `AGENTS.md` и нужные `.agents/skills/<name>/SKILL.md` явно. Отдельного регламента для конкретной модели нет.

## Первая инженерная задача

Создать минимальный запускаемый каркас и воспроизводимую быструю проверку после выбора стека и принятия решений о состоянии/доступе.

Критерии готовности этой задачи:

- из чистого checkout можно установить зависимости и запустить сервис по инструкции;
- есть одна документированная команда быстрой проверки, объединяющая применимые lint/typecheck/build и тесты; CI запускает ту же команду;
- интеграционные тесты проверяют контракт `/process`, оба шага пары, ретраи, конкурентные дубликаты и изоляцию состояния;
- начальные синтетические fixtures явно задают ожидаемые spans/типы и точный round-trip, а непокрытые категории перечислены;
- есть безопасные примеры конфигурации и исключения для секретов, runtime-данных, зависимостей и сборочных файлов;
- README содержит реальные команды; незапущенные проверки не отмечены как пройденные.

Конкретные команды и CI появятся вместе с реализацией этой задачи. Полный корпус качества, нагрузочный прогон и проверки сдачи выполняются по мере готовности продукта.
